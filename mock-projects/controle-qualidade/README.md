# Controle de Qualidade Industrial

Sistema para registro e análise de indicadores de qualidade em processos de produção.

## Funcionalidades
- Registro de não-conformidades por linha de produção
- Dashboard com gráficos de controle estatístico de processo (SPC)
- Exportação de relatórios em PDF

## Como rodar
\`\`\`
npm install
npm run dev
\`\`\`
